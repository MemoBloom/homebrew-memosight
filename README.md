# MemoBloom Memosight

## How do I install these formulae?

`brew install memobloom/memosight/<formula>`

Or `brew tap memobloom/memosight` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "memobloom/memosight"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
